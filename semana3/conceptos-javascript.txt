1. ¿Qué es JavaScript?

Respuesta: es un lenguaje de programacion que permite crear paginas web de una manera sencilla utilizando HTML y CSS para ejecutarse de una manera mas sencilla.

2. ¿Qué permite hacer Node.js en esta clase?

4. ¿Qué es una variable?

Respuesta: una variable son datos mutables que en cualquier momento pueden cambiar.

5. ¿Para qué se usa const?

Respuesta:es utilizada para definir una constante un valornumerico o palabras que siempre van a conservar status en el codigo.

6. ¿Para qué se usa let?

Respuesta: let representa que se va a utilizar o llamar una variable en el codigo.

7. ¿Qué significa if?

Respuesta: es (SI) en los diferentes lenguajes de programacion es una forma de condicional que permite variar el contenido del codigo dando a entender que hay mas opciones.

8. ¿Qué significa else?

Respuesta: es (SI NO) complemento del if cuando no se cumplen las condiciones que ya se tienen planificadas permitiendo otra opcion en la interfaz
